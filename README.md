# WishApp Java Web Application

A Java Servlet based web application that displays greeting and wishes dynamically using Java Servlets and Apache Tomcat.

This project demonstrates servlet processing, image handling, request-response management, and dynamic web page generation.

---

## Features

- Dynamic greeting messages
- Image display functionality
- Servlet based backend processing
- HTML page integration
- Apache Tomcat deployment

---

## Technologies Used

- Java
- Servlet API
- HTML5
- Apache Tomcat

---

```text
├── good-evening-wishes.jpg
│
└── WEB-INF/
    ├── web.xml
    └── classes/
        └── WishSrv.java
```

---

## How It Works

1. User opens the greeting page
2. Request is sent to the servlet
3. Servlet processes request dynamically
4. Greeting message and images are displayed
5. Output is generated in browser

---

## How to Run

1. Install Apache Tomcat
2. Copy project folder into Tomcat `webapps`
3. Start Tomcat server
4. Open browser:

```text
http://localhost:8080/WISHAPP
```
